# Локальная версия раздела инженерного консалтинга

Эта папка создана из текущей опубликованной версии сайта для последующего
встраивания в основной сайт компании. Публикационная версия и её репозиторий
не изменялись.

Из `index.html` удалены два самостоятельных раздела:

- `#projects` — «Объекты»;
- `#partners` — «Партнёры».

Ссылки на эти разделы и отдельный пункт «Контакты» удалены из локальной
навигации. Раздел `#contact` «Обсудить проект» и его форма сохранены; переход к
нему выполняют кнопки «Обсудить проект» и «Получить консультацию».

Остальные разделы, сценарии, изображения и обезличенный PDF сохранены без
изменений. В блоке рабочего отчёта оставлен один некликабельный титульный лист:
на широком экране он выровнен по высоте формы заказа, а на мобильном сохраняет
пропорции страницы. Поверх листа размещена отдельная кнопка для открытия примера
отчёта в PDF; кнопка расположена в нижнем правом углу и выровнена по нижней
линии с кнопкой отправки формы. Поле описания экспресс-анализа увеличено по
высоте. Вокруг листа добавлена тонкая равномерная белая рамка 6 px.
У фирменной фоновой текстуры удалены прямые полосы стыков. Неиспользуемые после
удаления блоков ресурсы также оставлены, чтобы локальная версия оставалась
максимально близкой к исходной.

Добавлен лид-магнит `#pricing` «Стоимость услуг»: он объясняет факторы
ценообразования и предлагает бесплатно получить на email предварительную оценку
формата работ, срока и диапазона стоимости. Форма использует общий механизм
заявок с типом `cost_estimate`.
